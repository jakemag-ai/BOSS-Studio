01 · The big ideaTwo modes, swapped constantly

The edit never lets the viewer rest on one image. Every 2–12 seconds it flips between two layouts, and a persistent word-by-word caption ties both together.

Why it works

  • Show every claim. Each spoken term gets a visual within ~0.3 s (avatar grid for “identity”, revenue chart for “sales”).
  • Face never disappears in Mode B, so trust and eye contact stay.
  • Fixed top title reminds viewers what the video is about, so late-joiners don’t leave.
  • Progress rail: the section pill (Identity Callout → Desire Frame → Proof Anchor) shows where you are.

04 · CaptionsWord-by-word, one or two words at a time

  • Position: horizontally centred; in Mode B it sits in the gap between graphic and speaker card (~y 1290 of 1920); in Mode A about two-thirds down (~y 1270) over the chest.
  • Font: heavy grotesk (Inter/Helvetica Black feel), white, tight tracking, ~60–70 px, slight drop shadow on Mode A.
  • Emphasis: key phrases switch to an italic serif (“Desire Hook Method.”). Pair one display serif italic with one grotesk for the whole video.
  • Behaviour: each word replaces the last (no karaoke fill, no big pop). Phrase breaks follow the speech rhythm; punctuation is kept.

05 · Graphics libraryReusable components to build

Title lockup

Top-centre, two lines. Line 1: serif italic + grotesk bold. Line 2: white bold text on a solid red bar, serif italic for the last words. Stays on screen throughout Mode B.

Section pill

Identity Callout Dark rounded rect, 1px light border, red left edge. In lists, the active pill is bright and the others are dimmed.

Dotted grid bg

Near-black (#050505) with a very faint dot grid, vignette to black. Keeps the black from feeling flat.

Phone mock

Rounded black device with a screenshot inside and a mini speaker clip at the bottom. Used for “content” references. Also appears with green UI icons (like/comment/share).

Stat card

Glass-dark rounded card, small label (“Revenue”), large number, neon-green line chart that draws left to right with glow.

Avatar grid + ring

5×5 grey person icons, one gets a red dashed ring, a dashed leader line and a red gradient label chip (“The identity of the person you want to buy”).

Flow diagram

Icon nodes (viewer → warning → target) joined by a vertical line that draws down. Text labels sit right of each node.

Doc card

Dark card with serif-italic heading, grey skeleton lines, red highlight bars and yellow underlines. Dashed line to a red label chip.

Orbit burst

Concentric rings of small red and green dots around a centrepiece, expanding outward for the “better proof” payoff.

06 · MotionHow things move

  • Graphics in: fade + 20–40 px slide/scale-up with a spring (damping ~14–18, no big overshoot), 8–12 frames. Blur-in on text is used in places.
  • Graphics out: short fade or slide-off, often replaced by the next card within the same beat (cards “hand off” to each other).
  • Sequential build: lists reveal an item every ~0.5–0.8 s, in sync with the spoken word.
  • Punch-ins: hard cut to a ~1.4–1.6× crop, then a slow scale drift (1.0 → 1.05) until the next cut. No whip pans or glitches.
  • Line draws: chart lines, connectors and dashed leaders animate with a path-length progress (strokeDashoffset).
  • Rhythm: never more than ~12 s on one graphic; the face punches back in every 2–4 s of speech.

08 · Build itRemotion implementation

Composition

  defaultProps={{ src: staticFile('head.mp4'), captions, scenes }} />

Scene data drives everything

type Scene = {
  from: number; dur: number;            // frames
  mode: 'punch' | 'split';
  section?: string;                      // pill label
  graphic?: 'avatars' | 'flow' | 'script' | 'proof' | 'orbit' | 'docs' | 'stat';
};

Layout switch

const Layout: React.FC<{scene: Scene; src: string}> = ({scene, src}) => {
  const f = useCurrentFrame();
  const drift = interpolate(f, [0, scene.dur], [1.45, 1.52]);
  if (scene.mode === 'punch')
    return <OffthreadVideo src={src} style={{width:'100%',height:'100%',objectFit:'cover',
      transform:`scale(${drift})`}} />;
  return (
    <AbsoluteFill style={{background:'#050505'}}>
      <DotGrid /><TitleLockup />
      <div style={{position:'absolute',top:360,left:60,right:60,height:820}}>
        {renderGraphic(scene.graphic)}
      </div>
      <div style={{position:'absolute',left:70,right:70,top:1408,bottom:0,
        borderRadius:36,overflow:'hidden'}}>
        <OffthreadVideo src={src} style={{width:'100%',height:'100%',objectFit:'cover'}} />
      </div>
    </AbsoluteFill>
  );
};

Spring-in helper

export const useIn = (delay = 0) => {
  const f = useCurrentFrame(); const {fps} = useVideoConfig();
  const p = spring({frame: f - delay, fps, config:{damping:16, stiffness:140}});
  return {opacity: p, transform: `translateY(${(1 - p) * 30}px) scale(${0.96 + 0.04 * p})`};
};

Workflow

  1. Record the talking head in 9:16 (or crop 16:9 to 9:16) with a dark, practical-lit background.
  2. Transcribe with Whisper → word timestamps → caption JSON.
  3. Mark scenes: for each key term, set a graphic and alternate punch / split.
  4. Build each graphic as its own component; keep them 6–12 s max.
  5. Render: npx remotion render DesireHook out.mp4 --codec h264.

09 · ChecklistBefore you export

  • Layout flips at least every 12 s; punch-ins every 2–4 s of speech.
  • Every spoken term has a visual in the first 10 frames of the word.
  • One accent colour for emphasis, one data colour (green) for charts.
  • Captions stay inside safe zones (not under the Reels UI at the bottom ~250 px or the right 120 px).
  • The CTA beat uses a keyword comment (“Lead”) with a visual of the thing they get.
  • Add a soft music bed and light whooshes on graphic hand-offs (not verified in the source).

Study notes only. Re-create the structure and feel with your own copy, assets and brand rather than copying the original’s graphics or text.
