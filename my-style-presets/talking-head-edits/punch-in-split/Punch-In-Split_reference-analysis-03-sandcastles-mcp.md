## Structure
- **Split layout [seen].** Same as reference 01: graphic stage on top, captions at about 66%, and a
  fixed rounded speaker window at the bottom.
- **Two stage backgrounds, switched by section [seen]** (new):
  - Light paper grey with a faint square grid, for Claude UI screens ("Claude Just Changed Social
    Media Forever", prompt, output, report, CTA).
  - Near-black with a dot grid, for concept diagrams (video grid, Content Director orbit,
    Sandcastles MCP pipe).
- **Punch-in layout [seen]:** tight face shot with a blurred background and teal/warm lights,
  no zoom. Used on "I'm not going to lie", "For example I can now just ask Claude", "With just that
  one prompt", "tell me exactly what to make", "truly is like...", "But the key is...", "because
  it's actually watching", "If you want to set this up for yourself... better content".

  (5.8-7.2 s).
- **Typewriter in the prompt box [seen]** while the speaker says the prompt word for word.
- **Light sweep [seen]:** a diagonal white glint passes over the output panel on "watch the videos visually".
- **Scroll [seen]:** the transcript doc scrolls up and the report panel slides in.
- **Orbit [seen]:** social icons circle a Claude tile on a dashed ring; a dotted line draws
  between icons as they arrive (25.6-28 s).
- **Diagram builds [seen]:** the Sandcastles logo scales up, the platform icons drop in and connect

- **Blurred list reveal [seen]:** "10 Example Content workflows" list builds line 1 to 10 with
  the items blurred, so it teases the content without showing it.
